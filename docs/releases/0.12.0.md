# 0.12.0 — Effect 4.0.0

Breaking for applications still on an Effect release candidate. Effect 4.0.0, the first
stable release of Effect 4, replaces the release-candidate line, and the SDK now requires it.
Nothing in the issuer, the key list or the SDK's API changed. Both packages and the server go
to 0.12.0 to keep one version across the release.

## Upgrade

Install `effect` and `@effect/platform-node` `4.0.0` or later, and
`@gjermundgaraba/effect-actions` `0.9.0` if you use the `/session` or `/effect-actions` entry
points. Effect's 4.0.0 release notes list its changes since rc.118; none affected this
repository.

## SDK

- The `effect` peer is `^4.0.0`; release candidates no longer satisfy it.
- The optional `@gjermundgaraba/effect-actions` peer is `^0.9.0`, the effect-actions release
  for Effect 4.0.0.
- The README installs `effect` from its `latest` tag, now Effect 4, instead of `effect@rc`.

## Issuer and development package

- Built on Effect 4.0.0 and effect-actions 0.9.0. No behaviour changes. The development package
  embeds the 0.12.0 server.
