# 0.24.1 — pixel-paper 0.15.0

The dashboard moves to pixel-paper 0.15.0. Nothing else changes: the issuer's endpoints, its
errors, the database, the SDK's API and its effect-actions peer are as in 0.24.0, so there is
nothing to upgrade. Every package and the server go to 0.24.1 to keep one version across the
release.

## Dashboard

- The sign-in, setup and editor forms are pixel-paper form cards: one busy state holds the
  submit button, the close glyph, cancel and the fields while a form sends, and focus moves to
  the submit button as it does.
- A dialog whose change is being saved stays open on Escape, a press on the veil and cancel
  until the issuer answers, so a refusal lands where it was asked for. A save the issuer does not
  answer within 20 seconds gives up with "The issuer did not answer in time. Check whether the
  change was made before trying again.", and the dialog can be left again.
- Fragment links and announcements use pixel-paper's shipped Commands.

## SDK, development package and CLI

- Unchanged; the development package embeds the 0.24.1 dashboard.
