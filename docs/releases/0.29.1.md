# 0.29.1 — Effect 4.0.6 cleanups

Nothing to do to upgrade. The database, the configuration, every endpoint and every peer range are as in 0.29.0, so an application on SDK 0.29.0 verifies against a 0.29.1 issuer and the reverse. Every package and the server go to 0.29.1 to keep one version across the release.

## Issuer

- A response stream that fails after its headers are sent still aborts the connection, so a client never mistakes a partial body for a whole one. Effect 4.0.6's Node server now does this itself, so the issuer's own wrapper is gone.

## CLI

- `login --no-browser` no longer accepts `--no-no-browser`, which opened the browser; it is now an unrecognized flag.
