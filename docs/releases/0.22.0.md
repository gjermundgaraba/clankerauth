# 0.22.0 — The dashboard in Foldkit

Nothing to upgrade. The issuer's endpoints, its database and its configuration are unchanged, so an application on SDK 0.22.0 verifies against a 0.21.0 issuer and the reverse. The SDK and the CLI do not change; every package and the server go to 0.22.0 to keep one version across the release.

## Dashboard

The dashboard and the sign-in, setup and consent pages are one [Foldkit](https://foldkit.dev) application, styled with [pixel-paper](https://www.npmjs.com/package/@gjermundgaraba-designs/pixel-paper).

- Clients, resources and API keys are sections at `/`, `/resources` and `/keys`.
- A change that revokes or destroys something is confirmed in a dialog first, and a refusal is shown where the change was asked for. New secrets and API keys are shown once, with copy buttons.
- Sign-in and setup name a missing or invalid field under that field. Setup asks for a password of 8 to 128 characters, the limits the issuer enforces.

## Issuer

- Serves `/resources` and `/keys` as dashboard pages, and the dashboard's own `woff2` fonts.
- Its Content Security Policy allows `data:` images (`img-src 'self' data:`).

## Development package

- Embeds the 0.22.0 server and the new dashboard.
