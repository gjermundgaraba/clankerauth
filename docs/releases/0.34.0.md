# 0.34.0 — Breaking: effect-actions 0.29 peer, Node 26.13, and no SDK `RequestPolicy`

The SDK's optional effect-actions peer and the administration contract's effect-actions peer move from `^0.26.0` to `^0.29.0`, every published package requires Node 26.13.0 or later, and the SDK no longer exports `RequestPolicy`. The Effect peer remains `~4.1.1`. The database, the configuration, the issuer's HTTP wire form and its OpenAPI document, and the SDK's verification are as in 0.33.0. Every published package and the issuer move to 0.34.0 together.

## Upgrading

1. **effect-actions 0.29 and Node 26.13.** Install `@gjermundgaraba/effect-actions` 0.29 alongside the SDK's `/session` or `/effect-actions` entry points or the administration contract, and run on Node 26.13.0 or later, which effect-actions 0.29 requires. effect-actions 0.27 to 0.29 change nothing clankerauth exports; its changelog lists what they add.
2. **`RequestPolicy` moves to effect-actions.** Replace `import { RequestPolicy } from "@gjermundgaraba/clankerauth-sdk"` with `import * as RequestPolicy from "@gjermundgaraba/effect-actions/RequestPolicy"`. It takes the same options and makes the same decision, so `make`, `allows` and `middleware` are used as before. An application that used the SDK's root entry only for `RequestPolicy` now needs effect-actions installed.

## SDK

- The optional `@gjermundgaraba/effect-actions` peer is `^0.29.0`.
- `RequestPolicy` is removed; the root entry exports `Verifier`.
- `engines.node` is `>=26.13.0`.

## Administration contract

- The `@gjermundgaraba/effect-actions` peer is `^0.29.0`, and `engines.node` is `>=26.13.0`.

## Issuer, CLI and development package

- Built on Effect 4.1.2 and effect-actions 0.29.0. The CLI and development package carry their own copy and require Node 26.13.0 or later.
