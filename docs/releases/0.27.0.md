# 0.27.0 — Breaking: effect-actions 0.19.0 peers, and pixel-paper 0.24.0

Breaking for applications on effect-actions 0.18. The SDK and the administration contract peer
`@gjermundgaraba/effect-actions` `^0.19.0`, formerly `^0.18.0`; the two ranges do not overlap,
so an application on 0.18 moves to 0.19 with them. The dashboard moves to pixel-paper 0.24.0.
The issuer's endpoints, its errors, its OpenAPI document, the database and the SDK's API are as
in 0.26.3, so an application on SDK 0.26.3 verifies against a 0.27.0 issuer and the reverse.
Every package and the server go to 0.27.0 to keep one version across the release.

## Upgrading

1. **effect-actions 0.19.0.** An application that uses the SDK's `/session` or
   `/effect-actions` entry points, or the administration contract, installs
   `@gjermundgaraba/effect-actions` `0.19.0`. It still requires Effect `~4.0.4`. Two of its
   changes may reach application code; its changelog lists the rest:
   - `Action.make`, `Authentication.make`, `ActionHttp.make` and `ActionRpc.make` throw where
     two different error schemas share one `_tag` in a call, counting the action's errors, the
     binding's and a protected action's authentication's. The SDK's `ProviderUnavailable` is the
     error its docs give `Authentication.make`; an action that also declares an error of its own
     tagged `ProviderUnavailable` is refused, so declare the SDK's export there instead.
   - Every message it throws at a misuse is reworded to name its fix; update code or tests
     matching an old one.

## Dashboard

- Built on pixel-paper 0.24.0, without a change to its source. 0.24 gives the rail a toggle and
  adds Panel's `shelf`, IconButton's `keyHint` and a key in Tips' messages; the dashboard has
  no rail and uses none of the new fields.

## SDK and administration contract

- The optional `@gjermundgaraba/effect-actions` peer is `^0.19.0`, formerly `^0.18.0`; their
  APIs are unchanged.

## Issuer, CLI and development package

- Built on effect-actions 0.19.0. The CLI carries its own copy, so installing it needs nothing.
- The development package embeds the 0.27.0 server and dashboard.
