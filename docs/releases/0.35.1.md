# 0.35.1 — Dependency refresh

Nothing to do to upgrade. The database, the configuration, every endpoint and every peer range are as in 0.35.0, so an application on SDK 0.35.0 verifies against a 0.35.1 issuer and the reverse. Every package and the server go to 0.35.1 to keep one version across the release.

## Issuer and development package

- Built on Better Auth 1.7.19 and better-call 1.4.5, from 1.7.14 and 1.4.4, with jose 6.2.17 and kysely 0.29.8. No Better Auth release in between adds a table or a column, so the startup migration has nothing to apply.
- The dashboard is built on the clankersuite design system 0.8.0. Nothing it shows changes.
- The image is built on the current digest of the Node 26.13.0 base image.

## SDK and CLI

- The SDK depends on jose 6.2.17, from 6.2.14.
