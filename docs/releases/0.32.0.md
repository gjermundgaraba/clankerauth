# 0.32.0 — Breaking: Effect 4.1 and effect-actions 0.25.0 peers

Breaking for applications on Effect 4.0, or on effect-actions 0.23 or 0.24. The database, the configuration, the issuer's HTTP wire form and its OpenAPI document, and the SDK's verification are as in 0.31.0, so an application on SDK 0.31.0 verifies against a 0.32.0 issuer and the reverse. Every package and the server go to 0.32.0 to keep one version across the release.

## Upgrading

1. **Effect 4.1 and effect-actions 0.25.0.** `@gjermundgaraba/clankerauth-sdk` and `@gjermundgaraba/clankerauth-admin-api` peer `effect` `~4.1.1`, formerly `~4.0.4` and `~4.0.5`, and the SDK's optional and the administration contract's `@gjermundgaraba/effect-actions` peer is `^0.25.0`, formerly `^0.23.0`. Neither range overlaps the old one, so an application moves to Effect 4.1.1 or a later 4.1 patch, with every `@effect/*` package at the same version, and to effect-actions 0.25 with them. effect-actions 0.25.0 needs Effect 4.1.1, whose `HttpApiSchema.StreamSse` its event streams rely on. Effect 4.1.0 breaks code of your own, not what clankerauth exports: `effect/Crypto` is replaced by the `effect/crypto/*` services, such as `SecureRandom` and `Digest`, and crypto is no longer in the runtime's default services; Effect's changelog lists the rest. effect-actions 0.24.0 and 0.25.0 make the services a native MCP feature's handler reads a request's, and a feature merged beside an MCP endpoint rather than passed as `features` a type error. Its `HttpServerRequest.MaxBodySize` now holds under `HttpRouter.toWebHandler`, and `McpServer.middleware` and `McpServer.visibility` around an MCP endpoint now apply to its action tools. None of them touches what clankerauth exports; the effect-actions changelog says how to migrate code that uses them.

## Administration contract

- The `effect` peer is `~4.1.1`, and the `@gjermundgaraba/effect-actions` peer `^0.25.0`.

## SDK

- The `effect` peer is `~4.1.1`, and the optional `@gjermundgaraba/effect-actions` peer `^0.25.0`.

## Issuer

- Built on Effect 4.1.1 and effect-actions 0.25.0.
- The MCP endpoint decodes a 2026-07-28 request's `Mcp-Name` header as Effect does, so a base64 spelling of a public tool's name other than the canonical one is admitted signed out, where it was answered 401. A malformed one is still refused.

## Dashboard

- Built on Foldkit 0.170.0 and pixel-paper 0.3.0, without a change to its source. Foldkit 0.170 moves to Effect 4.1. pixel-paper 0.2 adds MarkdownEditor, which the dashboard does not use, so its script is the size it was.

## CLI and development package

- Built on Effect 4.1.1 and effect-actions 0.25.0. Each carries its own copy, so installing it needs nothing new.
- A `clankerauth` flag that takes one value, given twice, is refused with the command's help, where the first value won.
- An answer with a status the contract does not declare prints `Decode: undeclared status code (<status> …)`, where it printed `Decode error (<status> …)`.
