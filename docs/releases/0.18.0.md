# 0.18.0 — Effect 4.0.3 and effect-actions 0.13.0

Breaking for applications on Effect 4.0.2, or on effect-actions 0.11.0 or 0.12.0. The issuer's endpoints and the key list format are unchanged, so an application on SDK 0.18.0 verifies against a 0.17.1 issuer and the reverse. Every package and the server go to 0.18.0 to keep one version across the release.

## Upgrade

Install `effect` and `@effect/platform-node` `4.0.3` or later, and `@gjermundgaraba/effect-actions` `0.13.0` if you use the `/session` or `/effect-actions` entry points. effect-actions 0.13.0 requires Effect `~4.0.3`; its changelog and 0.12.0's list the rest of their changes, none of which affected this repository.

## SDK

- The `effect` peer is `^4.0.3`, and the optional `@gjermundgaraba/effect-actions` peer `^0.13.0`.

## Issuer, CLI and development package

- Built on Effect 4.0.3 and effect-actions 0.13.0.
- The development package embeds the 0.18.0 server.
