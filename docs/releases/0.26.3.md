# 0.26.3 — Better Auth 1.7.12 and the dependencies around it

The server moves to Better Auth 1.7.12, with its @better-auth packages, and to the better-call 1.4.4
it pins, from 1.7.10 and 1.4.2. 1.7.12 verifies a JWT with its stored key's algorithm rather than
the token header's; the issuer signs its tokens and key lists with that plugin, and they verify as
before. The server also moves to kysely 0.29.7, which releases a connection whose transaction fails
to begin or roll back, and waits for running queries before a commit or rollback; the server opens
every transaction through it. jose goes from 6.2.12 to 6.2.13 in the server, the SDK and the
development issuer, and keeps the cause of the errors it raises.

The dashboard moves to pixel-paper 0.23.0 from 0.15.0 without a change to its source: the parts it
uses only gained optional fields, and its tests and browser checks pass. The development issuer
bundles the server and the dashboard, so it carries each of these. The issuer's endpoints, the
database, the administration contract and the SDK's API are as in 0.26.2. Every package and the
server go to 0.26.3 to keep one version across the release.
