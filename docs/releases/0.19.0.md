# 0.19.0 — Effect 4.0.4 and effect-actions 0.14.0

Breaking for applications on Effect 4.0.3, or on effect-actions 0.13.0. The issuer's endpoints
and the key list format are unchanged, so an application on SDK 0.19.0 verifies against a
0.18.0 issuer and the reverse. Every package and the server go to 0.19.0 to keep one version
across the release.

## Upgrade

Install `effect` and `@effect/platform-node` `4.0.4` or later, and
`@gjermundgaraba/effect-actions` `0.14.0` if you use the `/session` or `/effect-actions` entry
points. effect-actions 0.14.0 requires Effect `~4.0.4`; its changelog lists the rest of its
changes, none of which affected this repository.

## SDK

- The `effect` peer is `^4.0.4`, and the optional `@gjermundgaraba/effect-actions` peer
  `^0.14.0`.

## CLI

- An npm install of the CLI installs one `effect`. `@effect/platform-node` takes
  `@effect/platform-node-shared` by caret, and Effect 4.0.4's requires `effect` `^4.0.4`, so an
  install of 0.17.1 or 0.18.0 since then put a second `effect` under it. The CLI now depends on
  `@effect/platform-node-shared` at its own `effect` version.

## Issuer and development package

- Built on Effect 4.0.4 and effect-actions 0.14.0.
- The development package embeds the 0.19.0 server.
