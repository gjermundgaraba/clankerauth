# 0.29.0 — effect-actions 0.20.0 and Effect 4.0.6

Upgrade the SDK and the administration contract with effect-actions 0.20.0: their `@gjermundgaraba/effect-actions` peer moves from `^0.19.0` to `^0.20.0`, which runs on Node 26 alone. The `effect` peer stays `~4.0.4`. The database, the configuration and every endpoint are as in 0.28.1, so an application on SDK 0.28.1 verifies against a 0.29.0 issuer and the reverse. Every package and the server go to 0.29.0 to keep one version across the release.

## Issuer

- Built and tested against Effect 4.0.6 and effect-actions 0.20.0. The image runs Node 26.12.1.
- A request body over 64 KiB is answered once Node has read and dropped it: an empty 413 from an action route, `UnreadableRequest` (400) from the provider's endpoints. 0.28.1 closed the connection unanswered.
- An administration action called through `/mcp` still finishes what it started when its client disconnects, its provider writes and their compensation included, and shutdown waits for it. Effect 4.0.6 interrupts such a call, so the issuer now holds each action to completion itself; otherwise a disconnect could leave a client created but not linked to its resources.

## Dashboard

- Built on Foldkit 0.169.0 and pixel-paper 0.26.0. Foldkit 0.169.0 no longer drops characters typed into a field while a burst of updates is pending, and fixes portal and overlay bugs.
