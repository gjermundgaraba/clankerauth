# 0.33.0 — Breaking: effect-actions 0.26 peer

The SDK's optional effect-actions peer and the administration contract's effect-actions peer move from `^0.25.0` to `^0.26.0`. Applications using either integration must upgrade effect-actions with the clankerauth package. The Effect peer remains `~4.1.1`. Every published package and the issuer move to 0.33.0 together.

## Upgrading

Install `@gjermundgaraba/effect-actions` 0.26 alongside the SDK's `/session` or `/effect-actions` entry points or the administration contract. effect-actions 0.26 changes `Event.RevisionStorage.epoch` to an Effect; clankerauth does not use that API, but applications using it must wrap the epoch in an Effect as described in the effect-actions changelog.

## Dependencies

- The issuer and development package use Better Auth 1.7.14; the issuer and SDK use jose 6.2.14.
- The issuer, SDK, administration contract, CLI and development package build against effect-actions 0.26.1. The CLI and development package carry their own copy.
- Development and CI use Node 26.13.0 and pnpm 12.17.0; published packages continue to require Node 26.12.0 or later.
