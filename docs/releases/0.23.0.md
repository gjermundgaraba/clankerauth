# 0.23.0 — Breaking: issuer data from before 0.16.0 is no longer upgraded

## Upgrading

The issuer no longer carries the data upgrades for databases created before 0.16.0. Before
moving an older issuer to 0.23.0, start it once on 0.22.x, which applies them, and stop it.
A database created by 0.16.0 or later needs nothing.
