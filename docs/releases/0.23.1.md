# 0.23.1 — pixel-paper 0.13.0

The dashboard moves to pixel-paper 0.13.0. Nothing else changes: the issuer's endpoints, its errors, the database, the SDK's API and its effect-actions peer (`^0.17.0`) are as in 0.23.0, so there is nothing to upgrade. Every package and the server go to 0.23.1 to keep one version across the release.

## Dashboard

- Built on pixel-paper 0.13.0. Its new treegrid rows are for keyboard-driven lists, and the dashboard's lists of scopes and resources to tick are not, so they render as before. Its navigation was already links.

## SDK, development package and CLI

- Unchanged; the development package embeds the 0.23.1 dashboard.
