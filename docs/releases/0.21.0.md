# 0.21.0 — effect-actions 0.16.0

Breaking for applications on effect-actions 0.15.0. The issuer's endpoints, the key list format
and Effect are unchanged, so an application on SDK 0.21.0 verifies against a 0.20.0 issuer and
the reverse. Every package and the server go to 0.21.0 to keep one version across the release.

## Upgrade

Install `@gjermundgaraba/effect-actions` `0.16.0` if you use the `/session` or `/effect-actions`
entry points. Its one change: an MCP endpoint over HTTP serving actions alone has no 2026-07-28
subscriptions by default. Drop an `allowSubscriptions: false` from such an endpoint.

## SDK

- The optional `@gjermundgaraba/effect-actions` peer is `^0.16.0`.

## Issuer

- Administration over MCP (`/mcp`) has no subscriptions by effect-actions' default, where it
  turned them off itself. Its behaviour is unchanged.

## CLI and development package

- Built on effect-actions 0.16.0.
- The development package embeds the 0.21.0 server.
