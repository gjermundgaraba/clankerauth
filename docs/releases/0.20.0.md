# 0.20.0 — effect-actions 0.15.0, and administration over MCP without subscriptions

Breaking for applications on effect-actions 0.14.0. The issuer's endpoints, the key list format and Effect are unchanged, so an application on SDK 0.20.0 verifies against a 0.19.0 issuer and the reverse. Every package and the server go to 0.20.0 to keep one version across the release.

## Upgrade

Install `@gjermundgaraba/effect-actions` `0.15.0` if you use the `/session` or `/effect-actions` entry points. Its changelog lists its changes: `Testing`'s MCP client and request builder move to `ActionMcp`, and a failure an action does not declare is its call's defect on every surface. None of them changed this repository's behaviour.

## SDK

- The optional `@gjermundgaraba/effect-actions` peer is `^0.15.0`.

## Issuer

- Administration over MCP (`/mcp`) advertises `listChanged: false` and answers `subscriptions/listen` with "Method not found", where it advertised changes it never sent and held a subscriber's stream open. Its tools are the contract's, fixed at startup. A client that subscribed to tool-list changes stops doing so; nothing else changes.

## CLI and development package

- Built on effect-actions 0.15.0.
- The development package embeds the 0.20.0 server.
