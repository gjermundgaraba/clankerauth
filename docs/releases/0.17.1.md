# 0.17.1 — The CLI of 0.17.0, published

No behaviour changes. `@gjermundgaraba/clankerauth` 0.17.0 never reached npm: the SDK and the development package were published, and the CLI was refused, since npm had no trusted publisher for it. 0.17.1 is that CLI, and the first the release workflow publishes; the other packages and the server go to 0.17.1 to keep one version across the release.

## Upgrade

From 0.16.0, follow [0.17.0](0.17.0.md): its CLI changes arrive in 0.17.1. From the 0.17.0 SDK or development package there is nothing to do.
